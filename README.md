# Atelier Arquitetura

Site da disciplina de Projetos de Arquitetura, com cronograma, galeria de projetos e materiais de apoio.

## Rodar localmente

Com Node.js 24 instalado:

```sh
npm ci
npm run dev
```

Abra http://localhost:5173.

## Publicação

O site usa GitHub Pages porque todas as páginas podem ser geradas no build. A cada push na `main`, o GitHub Actions gera os arquivos estáticos e publica o site.

[Ver site](https://otijolo.github.io/projeto-nuvem/)
